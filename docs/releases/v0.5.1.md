# Citation Workflow v0.5.1

## Changes

- Added OSCOLA, ACS, AMA 11, Chicago 18 (author-date), IEEE, and MLA 9 to single-paper and batch reference generation.
- Ordered reference styles for practical relevance to biology, with APA first: APA 7, Vancouver, AMA 11, Harvard, ACS, Chicago 18 (author-date), IEEE, MLA 9, and OSCOLA. BibTeX, RIS / EndNote, and custom formatting follow.
- Bundled the six additional CSL styles locally, recorded their upstream source revision, and updated third-party attribution. Generating references requires no extra style download.
- Updated frontend asset URLs so returning visitors load the new citation engine.

## Validation

- Production bundle build and the full automated test suite passed (one existing Python test skipped).
- Tested all 11 built-in formats with journal articles, conference papers, and versioned preprints using the actual browser bundle.
- Verified matching single-paper and batch option ordering and distinct journal-reference output for each CSL style.

This release updates the GitHub Pages frontend; no separate Cloudflare Worker deployment is required.
