# Citation Workflow v0.2.0 — Batch downloads and custom references

Choose a Windows folder with the native folder picker, process multiple DOIs in one table, and learn a reference format from an example.

**[Open the website](https://marronyao.github.io/Citation_Workflow/)** · **[Read the setup guide](https://github.com/marronyao/Citation_Workflow#readme)**

## What's new

- **Folder setup before searching:** the save location now appears above Find paper, with a prompt asking where to save your papers. Type a path or select **Browse folders** to open the native Windows folder picker.
- **Batch download:** select the top-right button, choose a working folder and reference style, then paste one DOI per line. The results table shows each DOI, a shortened article title, a PDF download button and a citation-copy button.
- **Download all PDFs:** save the batch to the selected folder with one action. Papers are processed sequentially; failures do not stop the remaining downloads, and PDFs already saved to that folder during the batch are skipped. Failed downloads can be retried individually.
- **Custom reference styles:** choose **Custom · from an example** in single-paper or batch mode and paste a complete journal reference. Detection starts automatically and learns author-name conventions, field order, punctuation and page-range formatting. Including the example's DOI gives the most reliable match; references without a DOI can be identified through Crossref, with publication years helping distinguish originals from reprints.
- **Journal abbreviations:** custom styles follow the example's full or abbreviated journal-name convention and dotted or undotted form. Abbreviations come from PubMed or Crossref metadata. If no verified abbreviation is available, the full name is retained with a note.
- **Simpler citation panel:** the formatted preview has been removed. The editable plain-text citation is ready to copy directly. Custom examples and detected templates are shared between single and batch mode and saved in your browser.

## PDF source changes

- Third-party databases are tried before offering publisher access: PubMed Central, followed by Sci-Hub mirror candidates discovered through web search.
- Mirror URLs no longer need to be entered manually. If plain search pages provide no usable links, the companion retries with an isolated Chrome or Edge browser session.
- When no PDF is retrieved, publisher and search links are offered for you to choose. Nothing opens automatically.
- Additional database adapters can be added to the companion's source list.

## Upgrade from v0.1.0

1. Close the old companion's command window.
2. Download **Source code (zip)** from the release assets and extract it to a new folder.
3. On Windows with **Python 3.10 or later**, double-click **start.bat** and keep its command window open. No extra Python packages or Node.js installation are needed. The native folder picker uses Python's standard Tkinter component.
4. Refresh the website, or use the local page at **http://127.0.0.1:8765/**. The new custom-style detection and folder picker require the updated companion.

## Validation and limitations

Python and JavaScript checks, the production build, and desktop/mobile browser checks passed. Custom styles were also checked against a real published reference, both with and without its DOI. Browser interaction checks used simulated API replies for target papers and PDF downloads.

PDF availability depends on the source; search verification, institutional sign-in or manual downloading may still be required. Automatic Sci-Hub retrieval is not guaranteed. A single plain-text example cannot reveal every journal rule, so review generated references against the journal's instructions. Ambiguous examples prompt for a DOI instead of selecting a paper arbitrarily.
