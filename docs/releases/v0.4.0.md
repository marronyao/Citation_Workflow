# Citation Workflow v0.4.0 — Open the website and use it

## Changes

- Metadata lookup and full-text retrieval now run on a deployed Cloudflare Worker. No localhost connection, helper, Python, extension or project-file download is required.
- PDFs use normal browser downloads with article-title filenames. Browser settings control save location and duplicates; automatic download is optional and off by default.
- Batch download creates one ZIP with available PDFs and a report. Limits: 20 papers, 80 MB per PDF, 100 MB per ZIP. Failed or invalid items do not stop other papers.
- Citation styles, editable titles, reference-example custom formatting and simple GitHub feedback are preserved.
- Added expiring signed tickets, restricted source hosts/redirects, response limits, CORS and cloud rate limiting.

## Basic validation

- Real cloud PDF downloads: PMLR (Haarnoja et al., 2017), arXiv `1706.03762v1`, PLOS Biology `10.1371/journal.pbio.3000117`, Nature `10.1038/s41586-021-03819-2`, Journal of Statistical Software `10.18637/jss.v067.i01`.
- Browser: single conference-paper PDF; mixed batch with journal, preprint, conference paper and invalid input; ZIP with available PDFs and a report. Python independently verifies ZIP CRCs and contents.
- Automated legacy metadata/source regression tests, frontend identifiers/capitalisation, custom styles, citation exports, cloud tickets/CORS/host restrictions, PDF validation and ZIP integrity.

## Availability notes

The cloud checks original repositories, PMC and supported open-access publishers. Legacy headless-browser mirror discovery and automation for Sci-Hub, ResearchGate, Z-Library, Library Genesis and Anna’s Archive are not deployed. Subscription access, verification pages and cloud-network restrictions can still prevent PDFs; official article links remain available.

Windows browser downloads were tested. macOS is available but has not undergone complete testing; native Safari/mobile downloads remain unverified. No OS-specific installation is needed. Internet and cloud service availability are required.

Backend source/configuration are in `cloud/` and are deployed separately from Pages. GitHub Actions handles frontend publication and this release.
