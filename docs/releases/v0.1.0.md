# Citation Workflow v0.1.0 — Initial release

The first public release of Citation Workflow brings DOI lookup, PDF retrieval and reference formatting into one workspace for biological research.

**[Open the website](https://marronyao.github.io/Citation_Workflow/)** · **[Read the setup guide](https://github.com/marronyao/Citation_Workflow#readme)**

## What’s included

- **DOI lookup:** enter a DOI or a `https://doi.org/` link to find the paper in PubMed, with DOI metadata as a fallback.
- **PDF retrieval:** check PubMed Central and publisher pages, then an optional, user-supplied Sci-Hub mirror.
- **Windows downloads:** save PDFs to an existing folder using the original article title. Forward slashes, backslashes and surrounding quotation marks are accepted in folder paths; duplicate filenames receive a numeric suffix.
- **Reference formats:** generate APA 7, Vancouver, Harvard, BibTeX and RIS references.
- **Editable APA capitalisation:** apply sentence case to article titles and title case to journal names, with controls to preserve proper nouns and scientific terms.
- **Preview and copy:** review formatted references with italics, then copy them as plain text.
- **A focused interface:** dark mode, white and red typography, responsive layouts and British English throughout.

## Getting started

1. Download **Source code (zip)** from the assets below and extract it.
2. Install **Python 3.10 or later** on Windows, with Python available on your PATH.
3. Double-click **`start.bat`** and keep its command window open. No additional Python packages or Node.js installation are needed.
4. Use the local page that opens, or visit the website while the companion is running.
5. Enter a DOI, choose an existing save folder and review your reference.

## Known limitations

- The Windows companion is required for DOI queries and downloads, including when using the hosted website. GitHub Pages hosts the interface only.
- Browser restrictions may prevent the hosted page from connecting to the companion. If this happens, use **http://127.0.0.1:8765/** instead.
- Some publishers require institutional sign-in, CAPTCHA verification or a manual download. Browser sign-in sessions are not shared with the companion.
- No Sci-Hub mirror is included, and mirror availability has not been verified.
- Scientific names and proper nouns still need a final capitalisation check, especially when the supplied title is entirely in capitals.
- Downloads are limited to **80 MB**. Windows drive paths are supported; UNC network paths are not.

This is an early release. Feedback on metadata, reference formatting and publisher compatibility is welcome through [GitHub Issues](https://github.com/marronyao/Citation_Workflow/issues).
