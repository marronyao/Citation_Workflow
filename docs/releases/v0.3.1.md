# Citation Workflow v0.3.1 — Refresh cached website assets

This patch includes the cross-platform downloads and feedback features from v0.3.0 and fixes stale browser assets after website updates.

**[Open the website](https://marronyao.github.io/Citation_Workflow/)** · **[Setup guide](https://github.com/marronyao/Citation_Workflow#readme)**

## Changes

- Versioned CSS and JavaScript URLs ensure a refreshed page loads the matching application files, rather than reusing the previous release's cached assets.
- Feedback uses a muted speech-bubble icon and borderless text; Batch download keeps its red outline. The system selector supports Windows, macOS and Linux, defaulting to Windows on a first visit.
- Windows and Linux checks gate deployment. macOS checks run separately.

## Upgrade and testing status

Close the old companion, download and extract this release's **Source code (zip)** or **Source code (tar.gz)**, then start `start.bat` on Windows or run `sh start.sh` on macOS/Linux. Python 3.10 or later is required. Refresh the website afterwards.

**macOS support is available, but has not undergone complete testing.** Native macOS folder selection, browser permissions and end-to-end PDF downloads remain unverified. Windows and Ubuntu have been verified with actual PDF downloads.
