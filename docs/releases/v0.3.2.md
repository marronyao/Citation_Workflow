# Citation Workflow v0.3.2 — Simpler paper feedback

Feedback now opens one short form for paper download and citation problems.

**[Open the website](https://marronyao.github.io/Citation_Workflow/)** · **[Send feedback](https://github.com/marronyao/Citation_Workflow/issues/new?template=feedback.yml)**

## Changes

- Replaced the separate bug-report and suggestion templates with a single Paper feedback form.
- Choose **Paper download** or **Paper citation**, then enter the paper DOI or describe the citation problem. A DOI alone is enough for download reports.
- Contact email is optional. The form explains that email addresses are visible in the public GitHub issue.
- The website's Feedback link opens this form directly, avoiding the template chooser. Blank issues are disabled so only the feedback template is offered.

## Compatibility

Download and citation behaviour is unchanged. Windows and Linux checks run before deployment; macOS compatibility checks run separately.

**macOS support is available, but has not undergone complete testing.** Native macOS folder selection, browser permissions and end-to-end downloads remain unverified.
