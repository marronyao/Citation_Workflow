# Citation Workflow v0.4.1

## Changes

- Added a progress panel to Batch download, positioned above the results and kept visible when scrolling through long batches.
- Shows the current DOI or paper identifier, paper number, reference-data lookup and full-text search stages, completed steps and elapsed time. Long-running stages display a waiting message, with an activity indicator that respects reduced-motion preferences.
- Individual PDF downloads and Download all as ZIP now show their current task. PDF transfers report received megabytes and the total when available; ZIP creation reports how many files have been packed and yields between files so the browser can repaint.
- Completion messages distinguish processed papers, failed lookups, included PDFs and unavailable or skipped downloads. Failed items do not stop the remaining batch; controls and timers reset for another attempt.
- Updated versioned frontend asset URLs so returning visitors receive the new interface.

Progress measures completed tasks, not an estimated completion time. A finished batch can include unavailable PDFs. Existing limits remain 20 papers per batch, 80 MB per PDF and 100 MB per ZIP.

## Validation

- Full automated suite passed: Python metadata/source tests, frontend and citation-format checks, cloud API restrictions, PDF validation and independent ZIP integrity checks.
- Added regression coverage for slow lookup/source-search stages, failure continuation, retry resets, download failure cleanup, PDF byte progress with and without a known total, and ZIP packing progress.
- Local Chrome browser checks at desktop (1365 × 900) and mobile (390 × 844) sizes passed using controlled API responses: elapsed-time updates, stage changes, invalid-item continuation, completed progress and an actual browser ZIP download. No JavaScript errors or mobile page overflow were observed.
- Production bundle build passed. Native Safari and mobile-device downloads were not tested.

This release changes the frontend only; it requires no separate Cloudflare Worker deployment.
